## Projects

### 🏨 [04-StayEase-Project](./04-StayEase-Project) — Hotel Booking Test Suite
A complete test plan and **40-case test suite** across 4 modules (Search & Availability, Booking & Reservation, Payment & Checkout, Account & Booking Management), with a full **requirement traceability matrix** mapping all 40 cases back to 12 functional requirements.
- 100% requirement coverage, cases prioritized High/Medium/Low by business impact
- 6 of 10 high-priority cases concentrated on payment flows — the highest-risk area
- Includes test plan (objective, scope, entry/exit criteria) + demo web app used for execution

### 📝 [03-Registration-Project](./03-Registration-Project) — Registration Form Test Case Pack
**19 test cases** (positive, negative, boundary, edge) executed against a self-built registration form.
- 17 passed, 2 failed — real defects found through exploratory testing beyond the planned script
- Found a **High-severity security issue**: password field displayed input in plain text instead of masking it

### 🛒 [02-Checkout-Project](./02-Checkout-Project) — Test Design Techniques
Applies three core test design techniques to a checkout flow: **Equivalence Partitioning**, **Boundary Value Analysis**, and **Decision Table Testing**, deriving **28 structured test conditions**.
- Decision table models all 16 combinations of the discount-code eligibility logic
- Every test condition verified against a self-built demo checkout form with documented results

### 📚 [01-Theory](./01-Theory) — Manual Testing Fundamentals
Personal study notes on SDLC, Agile/Scrum, testing principles (early testing, defect clustering, pesticide paradox), black/white/grey-box testing, test case writing, test suite organization, and test estimation techniques.
